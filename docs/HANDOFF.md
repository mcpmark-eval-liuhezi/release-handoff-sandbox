# Quarterly Handoff Checklist

Steps to complete before each quarter-end release handoff:

- [ ] Confirm the release calendar and freeze date
- [ ] Tag the release and record the tag name
- [ ] Verify all merge trains have landed on the default branch
- [ ] Run the release smoke tests and archive results
- [ ] Publish the handoff notes gist with status line
- [ ] Confirm the incoming teammate has admin access to the repo
- [ ] Walk through open issues/PRs and reassign owners
- [ ] Publish the final handoff notes and close the tracking issue
